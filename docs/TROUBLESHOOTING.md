# ロケット かんせいしつ トラブル対応マニュアル

2026-10-11 時点（最新版は共有ドキュメント「ロケット かんせいしつ トラブル対応マニュアル」）

困ったら、まず「30秒チェック」で原因の場所を見つけ、症状別の表の「まずやること」を試す。どれでも直らなければ「最終手段」の順に再起動する。記録は PC のファイルに1件ずつ保存されているので、再起動しても消えない。

## 30秒チェック

画面の右上と、PC の黒いウィンドウを見れば、ほとんどの原因の場所が分かる。

| 見る場所 | ふつうのとき | おかしいとき → 見る表 |
| --- | --- | --- |
| 右上「保存」の表示 | 緑の「ファイルに保存済み ✓」 | 赤・「未保存あり」「保存サーバー未接続」 → 保存・サーバー |
| 右上「マイク」の表示 | 緑の「マイク: DJI MIC MINI …」 | 黄色・赤、別のマイク名 → マイク・音 |
| 画面いちばん上 | 何も出ていない | 赤い帯が出ている → 保存・サーバー |
| PC の黒いウィンドウ（start.bat） | 開いたまま | 閉じている → 保存・サーバー |
| 卓の案内（画面下のまん中） | オレンジ・緑の文字 | 赤い文字（エラー） → その文に従う。マイクのことならマイク・音 |
| スマホ受付の右上 | 緑の「つながっています」 | 赤 → スマホ受付・スマホ操作 |

ゲームの最中でも、保存サーバーが止まっていても遊び続けられる。あわてて画面を閉じない。

## マイク・音

マイクのトラブルの多くは、選んでいるマイクがちがうか、しきい値が会場の音に合っていないかのどちらか。

| 症状 | まずやること | それでもだめなら |
| --- | --- | --- |
| 右上が「マイク待機中（クリックで開始）」 | 画面をクリックするか、何かキーを押す | F5 で再読み込み |
| 声を出しても「いまの こえ」が動かない | 受信機の USB を挿しなおす → 管理者画面の「入力デバイス」で DJI を選んで保存 | 送信機の電源とペアリングのランプを確認。充電切れなら USB 給電しながら使う |
| 「マイクの使用が許可されていません」 | アドレスバー左のアイコン → マイクを「許可」→ F5 | Windows の「設定 → プライバシー → マイク」でブラウザを許可 |
| 「他のアプリが使用中」 | Zoom・Teams・DJI Mimo などを閉じる → F5 | PC を再起動（最終手段） |
| 「選んだマイクが見つからない」と出た | 管理者画面で入力デバイスを選びなおして保存 | — |
| 声を出しても発射しない | 管理者画面の「いまの入力」で声の dB を見て、「開始しきい値」をそれより下げる | スタンバイ中に Space（またはスマホの「いますぐ スタート」）で手動で発射 |
| 声を出す前に勝手に発射する | 「開始しきい値」を会場の音（待機中の「いまの こえ」）より 5〜10 dB 上げる | マイクをスピーカーから離す。「計測中は BGM を消す」がオンか確認 |
| 声を止めてもエンドレスが終わらない | 会場の音がしきい値より大きい。「開始しきい値」を上げる | 「エンドレスの最長」を短くする（そこで必ず終わる） |
| 会場がうるさくて、声を出していないのにロケットが上がる | 「のびはじめ（floor）」を会場の音より上げる | マイクを口に近づけて固定する |
| 右上に赤い「CLIP!」 | 音割れ。マイクのゲインを下げる | 本番中にゲインを変えたら、それまでの記録とは比べられない。必要なら「本日の記録をリセット」 |
| BGM が鳴らない | 何かキーを押す（ブラウザは操作するまで音を出さない）。PC の音量とスピーカーを確認 | 管理者画面で BGM がオンか、sound フォルダに曲があるか確認。「♪ 次の曲」で試す |
| 効果音が鳴らない | 管理者画面で効果音がオンか確認。飛んでいる間は鳴らないのがふつう（ブースターだけ鳴る） | — |

## 保存・サーバー

保存サーバー（黒いウィンドウ）が止まっても、記録は画面側に残り、サーバーが戻れば 5 秒ごとに自動で送りなおされる。

| 症状 | まずやること | それでもだめなら |
| --- | --- | --- |
| 画面上に赤い帯「保存サーバーにつながりません」 | 黒いウィンドウが開いているか確認。閉じていたら start.bat をダブルクリック | 右上が「ファイルに保存済み ✓」に戻るまで、ゲームの画面は閉じない |
| 黒いウィンドウを間違えて閉じた | start.bat をもう一度ダブルクリック。新しいタブが開いたら、古いタブは閉じてよい | — |
| 右上が「未保存あり・再送中」（赤） | そのまま続けてよい。サーバーが戻れば自動で保存される | 黒いウィンドウがなければ start.bat |
| 右上が「ファイルに保存中…」のまま | 1 日の記録が多いと数秒かかる。待つ | 1 分以上変わらなければ start.bat を開きなおす |
| start.bat の環境チェックで [NG] | 表示された案内に従う | PowerShell 版で NG なら Python 3 を入れる（「Add python.exe to PATH」にチェック） |
| 「Windows セキュリティの重要な警告」が出た | 「アクセスを許可する」を押す（スマホ受付に必要） | 押しそびれたら、スマホ受付だけ使えない。PC だけで遊べる |
| ポートが 8000 でなく 8001 などになった | 問題なし。記録と設定はファイルから戻る | マイクの選択だけ引き継がれないことがある。管理者画面で選びなおす |
| index.html を直接開いてしまった（赤い帯「start.bat から開いてください」） | そのタブを閉じて start.bat から開く | — |

記録の保存先は管理者画面の「記録」に出ている（ふつうはアプリのフォルダの data）。イベント後は data フォルダごと USB などにコピーする。

## スマホ受付・スマホ操作

スマホは PC と同じネットワークにいないとつながらない。スマホが使えなくても、PC のキー操作だけで全部遊べる。

| 症状 | まずやること | それでもだめなら |
| --- | --- | --- |
| スマホでページが開かない・「つながっていません」 | スマホの Wi-Fi が PC と同じか確認。テザリングなら PC の「モバイル ホットスポット」がオンで、スマホがそこにつながっているか | Windows のネットワークが「パブリック」だと届かないことがある。「プライベート」にするか、ファイアウォールで Python を許可 |
| スマホで「合言葉がちがいます」 | 管理者画面の QR コードを読みなおす | QR の下に出ている合言葉をスマホに入力 |
| 管理者画面のスマホ受付が「いまは使えません」 | PowerShell 版で動いている。Python を入れて start.bat から起動しなおす | start.bat を右クリック →「管理者として実行」 |
| 管理者画面に「ネットワークにつながっていません」 | PC のホットスポットをオンにするか Wi-Fi につなぐ。10 秒ほどで QR が出る | start.bat を開きなおす |
| スマホの「PC の そうさ」のボタンが押せない | 押したあとは PC が動くまで最大 2.5 秒押せない。少し待つ | 「PC で管理者画面などが開いています」と出ていたら、PC で閉じる |
| スマホに「PC が うごいていない」 | PC のゲーム画面が開いているか確認（タブを閉じていないか、スリープしていないか） | start.bat を開きなおす |
| スマホの設定で「暗証番号が ちがいます」 | PC の管理者画面と同じ暗証番号（初期値 0000） | 忘れたら「記録」の表の暗証番号の行を見る |
| 登録した子が順番待ちに出ない | スマホの「じゅんばんまち」にいるか確認。PC は 0.5 秒ごとに取りに来る | もう一度「とうろく」。だめなら PC で名前を入れて遊ぶ |
| 順番待ちを全部消したい | PC の管理者画面 → 運用 → 順番待ち「全部けす」 | 1 人ずつならスマホの「とりけし」 |

## 画面・操作

キーが効かないときは、まずゲームの画面を 1 回クリックしてから押しなおす（別のウィンドウが前にあることが多い）。

| 症状 | まずやること | それでもだめなら |
| --- | --- | --- |
| Space を押してもスタンバイにならない | ゲームの画面をクリックしてから Space。結果画面で名前を入れている途中なら Enter | 卓の案内が赤い文字ならマイクのエラー（マイク・音の表） |
| Ctrl+Shift+A で管理者画面が開かない | 卓の右側の赤い丸ボタンをクリック | 飛んでいる最中は開けない。Esc で中断してから |
| 全画面で Esc が効かない・全画面が解除できない | 全画面の解除は F キー（Esc は「中断」に使っている） | F11 |
| 画面が小さい・上下に黒い帯がある | F キーで全画面にする（16:9 のまま画面いっぱいに広がる） | プロジェクターの解像度を 1920×1080 にする |
| 会場が暗くて画面がまぶしい | 管理者画面 → マイク・計測 → 背景を「宇宙（暗い）」 | — |
| どのキーも効かず、画面が止まっている | F5 で再読み込み（記録と設定はファイルから戻る） | 最終手段 |
| 結果画面で名前を入れたいのに数字が入らない | 1〜4 は部門を選ぶキー。数字は名前に使えない | スマホの「さいきんの けっか」で名前を入れる |
| 結果画面に「ぶもんは？」 | 部門を選ばずに飛んだ。キー 1〜4 か、スマホで部門を選ぶ | — |
| 「スタンバイが じかんぎれ」で待機に戻った | 15 秒声がなかった。もう一度 Space | 声が出ていたのに戻るなら、開始しきい値を下げる |

## 記録

「破棄」「リセット」はランキングから外すだけで、ファイルには残っている。当日中に戻す必要がなければ、イベント後にまとめて直せばよい。

| 症状 | やること |
| --- | --- |
| 間違えて「この きろくを はき」「本日の記録をリセット」をした | data フォルダの `<日付>.json` をメモ帳で開き、その記録の `"deleted": true` を消して保存 → ゲーム画面で F5 |
| `<日付>.json` が壊れた・消えた | ほとんどは自動で直る（画面に残っている記録を送りなおす）。直らなければ data/history のいちばん新しいファイルを `data/<日付>.json` にコピー |
| history もない | `data/<日付>.log.jsonl`（1 行に 1 件）に全部残っている。イベント後に復元する |
| 名前を入れ忘れた・まちがえた | 直前の 8 件までならスマホの「さいきんの けっか」で直せる |
| 別の PC で続きをやりたい | アプリのフォルダごと（data 込みで）コピーして start.bat。sound フォルダの BGM も忘れずに |
| リハーサルの記録がランキングに残っている | 本番前に管理者画面 → 記録 →「本日の記録をリセット」 |
| 暗証番号を忘れた | data フォルダの settings.json の `"adminPin"` を `"0000"` に書き換えて保存 → ゲーム画面で F5 |

## 最終手段（記録を消さずに全部やり直す）

上から順に試し、直ったところで止める。どの段階でも記録と設定はファイルから戻る。

1. ゲームの画面で **F5**（再読み込み）。右上が「ファイルに保存済み ✓」、マイクが緑になるのを待つ
2. 黒いウィンドウを閉じる → **start.bat** をダブルクリック → 新しく開いたタブで続ける（古いタブは閉じる）
3. DJI の受信機を挿しなおし、管理者画面で入力デバイスを選びなおす
4. Chrome を全部閉じてから start.bat
5. PC を再起動 → start.bat → F で全画面 → スマホは QR を読みなおす

どうしても直らないときは、紙に名前と dB をメモして続け、あとで入れる。
