# ロケット かんせいしつ（きたのにほんいち・声の大きさゲーム）

声を出し続けると、その大きさでロケットが宇宙へ上がっていくゲーム。その日の 1 位を「チャンピオン（ゴースト）」として一緒に飛ばし、競争できる。
対象は幼稚園〜小学校高学年。プロジェクター（1920×1080）に映す「明るい管制室」の画面。
ビルド不要（素の HTML / CSS / JS）。Windows PC の Chrome / Edge を想定。

## 起動方法

1. `start.bat` をダブルクリック。黒いウィンドウで**環境チェック**が走り、問題なければブラウザが自動で開く。
   - 黒いウィンドウは本番中は閉じない（閉じてもゲームは続けられる。もう一度 `start.bat` を実行すれば未保存分は自動で再送される）。
2. 初回はブラウザのマイク許可ダイアログで「許可」。
3. 右上に「ファイルに保存済み ✓」と「マイク: （デバイス名）」が緑で出れば準備完了。
4. 何かキーを押すと BGM が始まる（ブラウザは操作するまで音を出さないため）。
5. `F` キーで全画面にして、PC をプロジェクターへ出力する。

> `index.html` を直接開いても動かない（画面上部に赤い案内が出る）。必ず `start.bat` から開くこと。

### 起動時の環境チェック（毎回自動）

| チェック | 問題があったとき |
|---|---|
| Python 3.8 以上があるか | 無ければ **Windows 標準の PowerShell 版サーバー（`server.ps1`）で起動**。インストール不要 |
| PowerShell 版の JSON 処理が正しく動くか（自己テスト） | 失敗したら止まって案内を出す（Python を入れれば確実） |
| `data/` フォルダに書き込めるか | 読み取り専用の場所なら `%LOCALAPPDATA%\kitano-decibel\data` に切り替えて、保存先を表示 |
| ポート 8000 が空いているか | 使用中なら 8001〜8010 を順に使う（記録はファイルから戻るので問題なし） |
| ブラウザ | Chrome → Edge（Windows 標準）→ 既定のブラウザ の順で開く |

## ゲームの流れ

1. 待機中にスタッフが **Space** → **スタンバイ**（BGM が自動で消える。15 秒だれも声を出さなければ待機に戻る）。
2. 声が **開始しきい値** を超えた瞬間に発射 → **ステージ1（5 秒）**。
   - 声が大きいほど速く上がる: 1 秒あたり `(声のdB − のびはじめ) × のびやすさ` km。
   - **もくひょう1「うちゅう」(100km)**、**もくひょう2「つき」(500km)**。
3. つきに届いたら、その場で **∞ エンドレスモード** へ。
   5 秒で届かなかったら **ブースター発射**（3 秒で つきまでワープ。この間の声は記録に入らず「おうえんメーター」に出る）→ エンドレスへ。**全員がエンドレスに行ける。**
4. エンドレスは最長 10 秒。**声が 1 秒とぎれたら終わり**。かせい・もくせい・どせい… と星を通りすぎていく。
5. **結果**: とどいた高さ（km）と場所、バッジ、きょうの順位。1 位を超えたら「しんきろく」演出。記録はこの時点で自動保存。
6. 名前を入れて **Enter**（入れなくてもよい）→ 待機へ。

ゴースト（チャンピオン）は、その日の 1 位の飛び方を同じ経過時間で再生する。画面の外にいるときは「▲ チャンピオン ○km さき」と出る。

## 操作（スタッフ）

| キー | 動作 |
|---|---|
| Space | 待機 → スタンバイ。スタンバイ中に押すと手動で発射。結果画面（名前が空のとき）は次の人のスタンバイへ |
| Esc | 中断（スタンバイ・飛行中。記録は残らない）。結果画面では名前なしで待機へ |
| Enter | 結果画面で名前を決定して待機へ |
| Delete | 結果画面でこの記録を破棄（確認あり。名前欄が空のとき） |
| F | 全画面の切替（全画面中は Esc を中断に使うため、解除は F） |
| Ctrl+Shift+A | 管理者画面（暗証番号。初期値 `0000`）。卓の右の赤いボタンをクリックしても開く。計測中は開けない |

## 管理者画面（当日の状況に合わせて変える）

保存すると `data/settings.json` とブラウザの両方に残る。

| カード | 項目 | 既定 |
|---|---|---|
| ゲーム | 名前入力 / ブースター / おうえんメーター / ゴースト | すべてオン |
| | ステージ1の時間 / エンドレスの最長 / 声がとぎれたら終了 | 5 秒 / 10 秒 / 1 秒 |
| 難易度 | のびやすさ（km/秒/dB）/ のびはじめ（floor） | 5 / 55 dB |
| | もくひょう1「うちゅう」/ もくひょう2「つき」 | 100 km / 500 km |
| | めやす（65・75・85・95 dB で うちゅう・つき まで何秒か、エンドレスで何 km のびるか） | 自動計算 |
| マイク・計測 | 入力デバイス / いまの入力（dBFS → dB）/ 開始しきい値 / 校正オフセット / 背景（明るい・暗い） | 既定のマイク / 65 dB / +100 |
| サウンド | BGM（音量）/ 計測中は BGM を消す / 効果音（音量）/ 計測中の効果音 / 試し再生 | オン / オン / オン / オフ |
| 記録 | 保存先・本日の記録の件数・CSV 出力・本日の記録をリセット | |
| 運用 | リハーサルモード（記録はファイルに残るが、ランキング・ゴーストに入れない）/ 暗証番号の変更 | オフ / 0000 |

**難易度の調整の目安**: 子どもの普通の大声で「つきに届くか届かないか」くらいが盛り上がる。会場で何人かに試してもらい、
「めやす」を見ながら のびやすさ・のびはじめ を変える。記録には、その回の難易度（`cfg`）も保存される。

## サウンド

- **BGM**: `sound/` フォルダに mp3 / ogg / wav / m4a を入れると、名前順にくり返し流れる（Git には入れない。素材サイトの規約で再配布禁止のため）。
- スタンバイ〜飛行中は BGM を自動で消す（スピーカーの音をマイクが拾って dB が上がらないように）。結果画面で戻る。
- **効果音**はアプリ内で合成（ファイル不要）。飛行中はクリア音などを鳴らさない（設定でオン可）。ブースターの音だけは鳴る（その間の声は記録に入らないため）。

## 本番前の機材セッティング

### DJI Mic Mini（レシーバーを USB-C で PC に接続。普通のマイクとして認識される）

- **DJI Mimo アプリで次を設定する**【要確認: メニュー名はファームウェア/アプリのバージョンで異なる】
  - 自動リミッター（セーフティトラック/リミッター系）: **OFF**
  - ノイズキャンセル: **OFF**
- **ゲインは本番前に固定し、本番中は触らない。** ゲインを変えると記録の公平性が崩れる。
- 送信機（マイク）は**スタンドで口から一定距離に固定**する（例: 口から 10〜15cm）。床にテープで立ち位置を示すとよい。
- バッテリー: 送信機 約 11.5 時間・受信機 約 10.5 時間（12 時間運用なら途中で充電 or 受信機を USB 給電）。

### ブラウザ・PC 側

- マイク入力は `echoCancellation` / `noiseSuppression` / `autoGainControl` をすべて OFF で取得している（生の音量を測るため）。
- Windows のサウンド設定（録音デバイスのプロパティ）に「ノイズ抑制」「音声強調」「AGC」がある場合も OFF にする。
- 右上に赤く `CLIP!` が出たら音割れ。マイクのゲインを下げる（本番前に調整して固定）。
- 長時間運用: 電源プランの「スリープ」「ディスプレイの電源を切る」を「なし」、Windows Update を一時停止、通知は「応答不可」に。

## 校正手順（dB を実際の騒音レベルに近づけたいとき）

画面の値は `dBFS + 校正オフセット`。既定のオフセット +100 は**仮の値**。順位付けだけなら校正は不要（全員同じ条件）。

1. スマホの騒音計アプリを、マイクのすぐ横（同じ位置）に置く。
2. 管理者画面の「いまの入力」に dBFS → dB が出る（オフセット欄を変えると、保存前でもその値で計算される）。
3. 一定の音を出し続け、スマホの値と dBFS を同時に読む。
4. `オフセット = スマホの dB − dBFS` を入力して保存。例: スマホ 85 dB / dBFS -18 → 103。

注意: スマホアプリは A 特性（dBA）が多く、本アプリは無加重なので完全には一致しない。**記録が入った後でオフセット・難易度を変えると、それまでの記録と比べられなくなる**。変えたら「本日の記録をリセット」してやり直す。

## 記録の保存（PC のファイルに自動保存）

記録は **1 件ごとに自動で PC のファイルに保存**される（ブラウザ内にも控えを持つ二重保存）。保存先は管理者画面に表示される。通常はアプリのフォルダ内の `data/`。

```
data/
  2026-10-10.json            その日の全記録（本体）
  2026-10-10.log.jsonl       記録を1件ずつ追記するだけのログ（最終保険。破棄・リセットしても消えない）
  history/2026-10-10_*.json  上書き前の世代コピー（直近20件）
  settings.json              設定（校正オフセット・難易度など）
  env-check.log              起動時の環境チェック結果
```

- 書き込みは「一時ファイルに書いてから置き換え」方式なので、保存の途中で PC が落ちてもファイルは壊れない。
- 送るのは変わった記録だけ。サーバー側でファイルの記録とマージする。ファイルが壊れて作り直された場合も、画面側に残っている記録を自動で送り直す。
- 保存サーバーが止まってもゲームは続けられる。右上が「未保存あり・再送中」（赤）になり、サーバーが戻ると自動で保存される。
- 「この記録を破棄」「本日の記録をリセット」はランキングから外すだけで、ファイル上には「破棄済み」として残る。
- 「CSV出力」: 順位・名前・高さ(km)・とどいた場所・平均dB・ブースター・記録時刻・クリップ（Excel でそのまま開ける UTF-8 BOM 付き）。
- 日付（PC のローカル日付）ごとに別ファイル。

**イベント後は `data/` フォルダごと USB などにコピーしておく。**

### 復旧方法

| 状況 | 方法 |
|---|---|
| 間違えて破棄・リセットした | `data/<日付>.json` を開き、該当記録の `"deleted": true` を消して保存 → ブラウザを再読み込み |
| `<日付>.json` が壊れた/消えた | `history/` の一番新しいファイルを `data/<日付>.json` にコピー。それも無ければ `.log.jsonl`（1行1記録）から復元できる |
| 別の PC で続きをやりたい | アプリのフォルダごと（`data/` 込みで）コピーして `start.bat` |

## 当日のトラブル対応

| 症状 | 対処 |
|---|---|
| 右上が「マイクエラー」/ 卓に赤字メッセージ | メッセージに従う。まず下の各項目を確認 |
| マイクが出ない・音量が動かない | 管理者画面 → 入力デバイスで DJI のレシーバー（DJI MIC MINI など）を選ぶ。USB を挿し直したら再度選択 |
| 「マイクの使用が許可されていません」 | アドレスバー左の鍵/設定アイコン → マイクを「許可」→ F5。Windows の「設定 → プライバシー → マイク」も確認 |
| 「他のアプリが使用中」 | Zoom / Teams / DJI Mimo などマイクを掴んでいるアプリを閉じる |
| 「マイク待機中（クリックで開始）」 | 画面をクリックするか何かキーを押す（ブラウザの自動再生制限） |
| 発射しない | 開始しきい値が高すぎる、またはマイクが別デバイス。管理者画面の「いまの入力」で声を出して確認 |
| 声を出す前に発射してしまう | 開始しきい値が環境音より低い。管理者画面で上げる |
| BGM が鳴らない | 何かキーを押す。`sound/` に音楽ファイルがあるか、管理者画面の BGM がオンか確認（「♪ 次の曲」で試せる） |
| Ctrl+Shift+A で管理者画面が開かない | 卓の右側の赤い丸ボタンをクリック |
| CLIP! が出る | マイクのゲインを下げる。本番中に変えたら全員やり直し |
| 上部に赤帯「保存サーバーにつながりません」 | `start.bat` の黒いウィンドウが閉じていないか確認。閉じていたらもう一度 `start.bat` → 未保存分は自動で再送 |
| 環境チェックで `[NG]` | 表示された案内に従う。PowerShell 版で NG なら Python 3 をインストール（https://www.python.org/downloads/ 、Add python.exe to PATH にチェック） |
| 暗証番号を忘れた | `data/settings.json` の `"adminPin"` を `"0000"` に書き換えて、ブラウザを再読み込み |
| 全画面で Esc が効かない | F で全画面を解除してから操作 |
| ページを誤って閉じた | `start.bat` から開き直せば、ファイルから記録・設定が戻る |
